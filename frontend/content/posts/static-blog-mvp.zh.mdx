# 为什么搭建这个个人博客

这个博客先不是一个完整产品，也不是一个需要马上运营起来的内容平台。它更像是一个长期记录的地方，用来放下各种随笔、想记的东西，以及学习新技术时留下的理解和阶段性复盘。

我目前更关注 Agent 智能体、大模型开发、Web 工程实践和个人项目复盘。这些内容如果只停留在聊天记录、临时文档或零散文件里，很容易过一段时间就找不到上下文。把它们整理成文章，至少能让每一次学习和尝试留下可回看的痕迹。

## 为什么先做轻量版本

第一版刻意保持简单，只保留写作、浏览、搜索、主题切换、SEO、RSS 和静态部署这些刚需能力。评论、统计、后台管理、图床、CMS、复杂多语言和更重的交互功能都先不做。

这样做的原因很直接：现在最重要的是让博客稳定可写、可部署、可持续维护，而不是一开始就把精力放在复杂系统上。内容还没有积累起来之前，过早加入太多功能只会提高维护成本。

## 这个博客会记录什么

后续内容会分成几个方向慢慢补充：

- 日常随笔、阅读感受和想留下来的片段。
- Agent 智能体、大模型开发和相关工具链学习。
- Web 工程实践、静态站点、部署和自动化流程。
- 个人项目过程记录、问题复盘和阶段性总结。
- 游玩过程中拍下的照片和生活记录。

其中技术笔记和项目记录会相对更结构化，生活随笔和照片记录可以更轻松一些。这个区分能让首页保持温和，也让技术内容有独立入口。

## 后续怎么完善

接下来最重要的不是继续堆功能，而是补真实内容。先把个人信息、项目列表和示例文章清理干净，再逐步写几篇实际记录。等内容值得公开分享之后，再考虑正式域名、国内访问、HTTPS、CDN 和更完整的发布流程。

这个博客的目标不是一次性完成，而是能长期留下东西。只要后续添加文章和图片足够方便，它就已经完成了第一阶段的价值。
