# Writing Template

Use this draft as the starting structure for a new article. Keep `draft: true` until the content is ready.

## Background

Explain the context: what problem you are solving, what triggered the note, and who the note is for.

## Problem

Describe the specific technical problem or decision.

## Solution

Explain the final approach and why it fits.

## Implementation Notes

Use short sections and focused examples. Add a language tag to every code block.

```ts
export function example() {
  return 'replace this with real code';
}
```

## Image Example

Use descriptive alt text:

```mdx
![Screenshot of the generated static output](/images/posts/article-slug/static-output.png)
```

## Summary

Record the final decision, tradeoffs, and follow-up items.

## Pre-Publish Checklist

- [ ] Frontmatter is complete.
- [ ] `date` and `updated` are quoted `YYYY-MM-DD` strings.
- [ ] Code blocks include language tags.
- [ ] Images have meaningful alt text.
- [ ] `corepack pnpm content:check` passes.
- [ ] `draft` is changed to `false` only when ready to publish.
