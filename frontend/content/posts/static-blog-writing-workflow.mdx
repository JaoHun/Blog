# Static Blog Writing Workflow

This draft shows the expected shape of a practical technical note. It is a reference example and should remain unpublished until copied into a real article.

## Background

The blog uses MDX files as the only article source. Each post should be understandable as a standalone technical note and safe to publish through static generation.

## Common Mistake

Do not leave required fields empty:

```yaml
title: ""
date: 2026-07-01
excerpt: ""
tags: []
```

The date above is also wrong because it is not quoted.
