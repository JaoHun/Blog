# Why I Built This Personal Blog

This blog is not meant to start as a complete product or a heavy publishing platform. It is a long-term place for notes, things worth remembering, and the thoughts that appear while learning and building.

I am currently interested in Agent systems, LLM development, Web engineering, and project retrospectives. If these notes stay only in chats, temporary documents, or scattered files, the context disappears quickly. Turning them into posts gives each learning step a stable record.

## Why the First Version Stays Small

The first version is intentionally lightweight. It keeps the essentials: writing, browsing, search, theme switching, SEO, RSS, and static deployment. Comments, analytics, admin publishing, media libraries, CMS integration, advanced i18n, and heavier interactions can wait.

The reason is practical: the site needs to be stable, easy to write in, and easy to deploy before it needs more features. Adding too much before the content exists would only make maintenance harder.

## What This Blog Will Contain

The content will grow in a few directions:

- Personal essays, reading notes, and small fragments worth keeping.
- Agent systems, LLM development, and related tooling.
- Web engineering, static sites, deployment, and automation.
- Project process notes, problem reviews, and stage summaries.
- Photos and life records from trips or daily moments.

Technical notes and project records can stay more structured. Personal essays and photo records can stay lighter. This keeps the home page warmer while still giving technical content a clear section.

## What Comes Next

The next useful work is not adding more product features. It is replacing placeholders, cleaning up personal information, improving the project list, and writing a few real posts. After the content is worth sharing, the site can move toward a stable domain, domestic access, HTTPS, CDN, and a more complete publishing workflow.

The goal is not to finish everything at once. The first stage is valuable as long as adding posts and images remains simple.
